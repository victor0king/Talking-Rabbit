Figure 1: Five Functional Layers of Talking Rabbitt Architecture
Decoupled agentic pipeline providing schema degradation defense and verifiable numerical outputs
§III System Design
Layer 1
Schema Resilience & Ingestion
Handles raw CSV/XLSX uploads. Auto-cleans null values, parses dates across diverse formats, imputes missing records, and normalizes abbreviated or corrupted headers (D0–D4 transformations).
View Layer
Layer 2
Conversational Semantic Parser
Translates ambiguous user queries (text or voice) into structured analytics tool calls. Intercepts intent, detects underspecified requests, and validates parameters against detected schema metadata.
View Layer
Layer 3
Deterministic Analytics Engine
Vectorized local Python computation via Pandas, Scipy, and Scikit-Learn. Executes DBSCAN clustering, Isolation Forest anomaly scoring, Pearson correlation matrices, and time-series forecasting without LLM math hallucinations.
View Layer
Layer 4
CBW Guardrail & Calibrator
Flags Confident-But-Wrong (CBW) scenarios when LLMs latch onto decoy columns (e.g. rev_adj vs tot_rev). Enforces uncertainty hedging markers and validates outputs within a ±1.5% ground truth tolerance band.
View Layer
Layer 5
Interactive Synthesis & Viz
Auto-renders responsive Chart.js visual models, dynamic correlation heatmaps, 2D PCA cluster scatters, KPI cards, and executive SWOT intelligence summaries.
